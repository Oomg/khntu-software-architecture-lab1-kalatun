# Опис системи: Online Ticket Booking & Event Platform

## 1. Призначення системи
Система призначена для онлайн-продажу квитків на концертні, театральні та спортивні події. Вона забезпечує користувачам можливість переглядати афішу, обирати місця на інтерактивній схемі залу, безпечно оплачувати замовлення та отримувати електронні квитки. Платформа також містить механізми захисту від масової скупки квитків перекупниками (ботами).

## 2. Бізнес-цілі
* Забезпечити швидкий та зручний процес купівлі квитків для кінцевих користувачів.
* Гарантувати безперебійну роботу системи під час пікових навантажень (старт продажу квитків на топові події).
* Мінімізувати фінансові та репутаційні ризики організаторів шляхом блокування ботів-перекупників.
* Надати організаторам подій зручний інструмент для управління квотами квитків та ціноутворенням.

## 3. System Scope (Межі системи)
**Входить до системи (In Scope):**
* Каталог подій та пошук.
* Інтерактивна схема залів та бронювання місць (з блокуванням місця на час оплати).
* Модуль захисту від ботів (обмеження кількості квитків на одного користувача/IP, CAPTCHA).
* Особистий кабінет користувача (зберігання електронних квитків у PDF/QR).

**Не входить до системи (Out of Scope / Зовнішні інтеграції):**
* Процесинг платежів (використовується зовнішній Payment Gateway, наприклад, Stripe або LiqPay).
* Розсилка Email/SMS (використовується зовнішній сервіс, наприклад, SendGrid або Twilio).
* Фізичний контроль доступу на локації (сканування QR-кодів на турнікетах виконується окремим застосунком організатора).

## 4. Stakeholders & Concerns Matrix (Матриця стейкхолдерів)

| Stakeholder (Стейкхолдер) | Роль / Відношення до системи | Concern (Занепокоєння / Інтерес) |
| :--- | :--- | :--- |
| **Кінцеві користувачі (Покупці)** | Основні споживачі послуг системи. | Зручність інтерфейсу, швидкість завантаження схем залів, безпека платіжних даних, гарантія отримання квитка після оплати. |
| **Організатори подій** | Створюють події, встановлюють ціни та схеми залів. | Точність фінансової звітності, відсутність простоїв системи під час старту продажів, захист від перекупників. |
| **Backend-розробники** | Реалізують бізнес-логіку та API. | Модульність коду, зрозумілість архітектури, простота реалізації транзакцій (уникнення подвійного продажу місць). |
| **DevOps / Інфраструктурні інженери** | Забезпечують розгортання та підтримку серверів. | Можливість швидкого автомасштабування (Auto-scaling) ресурсів, моніторинг навантаження, вартість володіння хмарною інфраструктурою. |
| **Служба безпеки (Security)** | Відповідають за захист системи від атак. | Захист персональних даних (GDPR), стійкість до DDoS-атак та бот-мереж, безпечна інтеграція з платіжним шлюзом. |
