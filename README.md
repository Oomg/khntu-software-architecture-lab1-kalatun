# Архітектурна документація: Online Ticket Booking & Event Platform

Цей репозиторій містить результати виконання Лабораторної роботи №1 з дисципліни «Проєктування архітектури, специфікація та стандарти інженерії».

## 🎯 Про проєкт
Проєкт являє собою базову архітектурну документацію для платформи онлайн-бронювання квитків. Мета системи — забезпечити зручний процес купівлі квитків, витримувати пікові навантаження під час старту продажів на топові події та захистити бізнес від ботів-перекупників.
